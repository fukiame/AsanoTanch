## setting up the bot:


<details>
  <summary>How to setup</summary>
  
- `git clone https://github.com/fukiame/AsanoTanch`
- `cd OdinRobot`
- `cp sample_config.ini config.ini`
- *Fill in all the vars*
- `pip3 install -U -r requirements.txt`
- *And finally* `python3 -m tg_bot`

*Enjoy!*
</details>
